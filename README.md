# 📱 Probaho Browser Mobile

The official mobile companion to [Probaho Browser](https://github.com/susankarkarmakar-pixel/probaho-browser). 

Probaho Browser Mobile is a privacy-first, fast, and secure web browser designed specifically for **Android** and **iOS** devices. It brings the core privacy and productivity features of the desktop version to your mobile device, ensuring a seamless and user-controlled browsing experience on the go.

## 🌟 Key Features
- 🔒 **Privacy First:** Built-in tracker and ad blocking, DNS-over-HTTPS (DoH) support, and strict per-site permissions.
- 🕵️ **Private Browsing:** Isolated private tabs with no persistent history, cookies, or cache.
- 🚀 **Performance:** Optimized for mobile devices with lazy loading and efficient memory management.
- 📑 **Tab Management:** Support for multiple tabs, tab groups, and quick switching.
- 🛠️ **Productivity Tools:** Integrated reading mode, download manager, and secure bookmark syncing (coming soon).

## 🛠️ Tech Stack
- **Framework:** React Native / Flutter 
- **Language:** TypeScript / Dart
- **Core Engine:** WebView (WKWebView for iOS, Android System WebView / GeckoView)

## 🔗 Related Projects
- 🖥️ **[Probaho Browser (Desktop)](https://github.com/susankarkarmakar-pixel/probaho-browser):** The main desktop application built with Electron, React, and TypeScript.

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/susankarkarmakar-pixel/probaho-browser-mobile.git`
2. Install dependencies: `npm install` or `yarn install`
3. Run on Android: `npm run android`
4. Run on iOS: `npm run ios`
